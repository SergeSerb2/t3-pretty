# T3 Pretty logo explorations

Studies that led to the shipping lockup T3. Live assets are in `assets/pretty/`
and `assets/pretty/kit/`: pastel mint T3 (`#8FCFA8`) on cream, frosted-glass
macOS icon, `T3 | Pretty` wordmark.

Open `board.html` in a browser to review the other directions.

## What's here

- `vector/` — earlier SVGs using the official T3 Code letterform, recast in
  World Scenery inks (forest `#14261B`, sage `#DFEFE3`, cream `#F4F1EA`).
- `raster/` — style studies. `25-lockup-t3-pretty.jpg` is the lockup that
  shipped (letterform only; live color is pastel mint on cream/glass).
