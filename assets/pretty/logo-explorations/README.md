# T3 Pretty logo explorations

Candidates for a quieter mark. The live icon in `assets/pretty/` is unchanged.

Open `board.html` in a browser to review everything on one page.

## Why

The current mark is a purple-to-orange 3D T3 on nested glass. It reads as a generated
app icon. T3 Pretty's product is fog, sage frost, and a photograph — the mark should
feel like that, and still sit in the T3 Code family.

## What's here

- `vector/` — production-ready SVGs using the official T3 Code letterform, recast in
  World Scenery inks (forest `#14261B`, sage `#DFEFE3`, cream `#F4F1EA`).
- `raster/` — style studies: app icons, wordmarks, landscape-as-mark, analog materials.
  Letterforms in the rasters are directional, not final.
