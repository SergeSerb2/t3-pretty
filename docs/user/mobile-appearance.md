# Mobile appearance

T3 Code Mobile uses the World Scenery theme — alpine greens that match the desktop wallpaper look,
including the pastel sage user bubble. Light and dark colors apply throughout the app, including
code reviews, file previews, the terminal, native headers, and sheets.

To change the color scheme:

1. Open **Settings**.
2. Select **Appearance**.
3. Select **System**, **Light**, or **Dark**.

**System** follows the device appearance automatically. Color scheme, text, code, and terminal
appearance preferences are stored on the device.
