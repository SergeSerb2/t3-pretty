# Mobile appearance

T3 Code Mobile defaults to the World Scenery theme — alpine greens that match the desktop
wallpaper look, including the pastel sage user bubble. It also includes T3 Chat, Grove, Ocean,
Ember, and Iris. Each theme has light and dark colors that apply throughout the app, including
code reviews, file previews, the terminal, native headers, and sheets.

To change themes:

1. Open **Settings**.
2. Select **Appearance**.
3. Choose a theme.
4. Select **System**, **Light**, or **Dark**.

**System** follows the device appearance automatically. Theme, text, code, and terminal appearance
preferences are stored on the device.
