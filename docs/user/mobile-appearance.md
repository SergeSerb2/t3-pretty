# Mobile appearance

T3 Code Mobile uses the World Scenery theme by default — alpine greens that match the desktop
wallpaper look, including the pastel sage user bubble. Light and dark colors apply throughout the
app, including code reviews, file previews, the terminal, native headers, and sheets.

To change the look:

1. Open **Settings**.
2. Select **Appearance**.
3. Under **Personalization**, choose a photo theme (**World Scenery**, **Night Cities**,
   **Deep Forest**, **Night Sky**, **Grand Buildings**) or **Boring**. Boring restores the original
   T3 Chat colors and turns landscape photos off. The photo themes keep the same alpine palette
   and change only the pictures behind the glass.
4. Select **System**, **Light**, or **Dark** for the color scheme.

**System** follows the device appearance automatically. Color scheme, text, code, and terminal
appearance preferences are stored on the device.
