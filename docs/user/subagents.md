# Subagents

Ask your agent to delegate part of a task when you want work to run in parallel.
You can name the provider and model in your request. T3 Code can start delegated
tasks through its orchestrator tools, and providers can also start their own
native subagents.

Open the **Agents** panel in a thread to view its child tasks, their progress,
and their results. Stop a running child from that panel when you no longer need
its work.

Available providers and models come from the thread's environment. Configure
them in **Settings → Providers**.
