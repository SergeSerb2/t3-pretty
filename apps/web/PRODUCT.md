# Product

## Register

product

## Users

Developers who direct coding agents throughout the day from desktop, web, or mobile, including across remote machines. They need dense, dependable visibility into agent work, source control, terminals, and approvals without losing their place.

## Product Purpose

T3 Pretty is a personal, style-focused T3 Code control surface. It preserves the open, provider-agnostic, remote-ready workflow and data compatibility while making the interface more legible, expressive, and pleasant to use. Success means important state is visible at a glance, actions behave consistently across surfaces, and visual changes never trade away performance or capability.

## Brand Personality

Polished, direct, personal. The product should feel calm during long sessions, candid about background state, and confident without becoming ornamental.

## Anti-references

- Coding tools that hide consequential state behind background jobs or vague spinners.
- Generic AI dashboards that add decorative cards, gradients, or motion without improving the workflow.
- Visually ambitious interfaces that sacrifice keyboard access, remote use, constrained layouts, or frame stability.

## Design Principles

- Show consequential state where the related action already lives.
- Keep the common path compact; reveal explanation progressively.
- Reuse one interaction and status vocabulary across web, desktop, and mobile.
- Prefer honest unknown states over confident guesses.
- Treat responsiveness, accessibility, and performance as product behavior.

## Accessibility & Inclusion

Controls must remain keyboard and screen-reader accessible with visible focus. Status cannot rely on color alone. Respect reduced-motion preferences, coarse pointers, constrained windows, and light and dark themes.
